# Anshika Birthday Surprise ❤️

Open `index.html` to preview.

To publish free with GitHub Pages:
1. Create a public GitHub repository named `birthday-surprise`.
2. Upload `index.html` and all five `anshika-*.jpeg` files.
3. Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
4. GitHub will provide the `github.io` URL.
